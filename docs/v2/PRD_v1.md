## 1. What it is

**1.1 一句话。** V2 是个人网站的**完整重做**：设计地基（字体、字号、版式、色彩、间距、组件、交互）从零开始；内容、留言板后端、域名、部署方式沿用。`[已定]`（"彻彻底底的重新来一遍"，"设计层面的零到一"）

**1.2 它不是什么。**
- 不是求职站，不面向招聘者，**访客是任何人**。`[已定]`
- 不是现有网站的小修小补。`[已定]`
- 不追求极简。`[已定]`

**1.3 谁拥有它。** 站点主人对它有**绝对的掌控权和自由**，不受现有版式和风格的任何限制。`[已定]`

**1.4 它怎么存在。** V2 只存在于本地 `v2` 分支，线上的网站保持原样。只有在站点主人明确接受之后，才合并上线；不接受，整个分支删除，不影响线上任何东西。`[已定]`

## 2. Experience principles

这一部分是**原则和边界**，不是具体画面。具体画面在第 3 部分，而且会随做出来的手感调整。

**P1. 大胆，且别处没有。** 要的是让人停下来的东西，不是安全的东西。 `[已定]`（"我要的就是大胆的"）

**P2. 交互是主角。** 页面之间和页面内部都有值得玩的交互。 `[已定]`

**P3. 向朋友的站学"交互思路"，不学她的"样子"。** `[已定]`
还留着的（这是我从她的站里提炼的，以第 3 部分为准）：
- 滚动是一个可逆的过程，不只是"看更多内容"。
- 进入和退出：不是页面跳转，是走进去、再退出来。

已删除（2026-11-14，站点主人："太有故事感了，不需要"）：鼠标是有含义的工具；每个场景一句话教会怎么玩；统一线索加每章不同场景和动词。

不能学的：她的比喻（窗花纸、CD 机、教堂、画廊）、她的内容、她的布局和视觉风格。

**P4. 向 ghostk.id 学"存在感和语气"，不学像素风。** `[已定]`
可以学的：
- 一个不重载的"环境"，中间的舞台在换内容。
- 此刻面板：对方和你并排的时间，真实的状态。
- 到处是自己的语气和幽默：404、空状态、"还没写"。
- 明确告诉访客"怎么玩"，并且有静音开关。

已删除（2026-11-14）：会说话的小角色。

不能学的：像素风和复古桌面的视觉语言。

**P5. 事实，不是题材。** `[已定]`
项目管理相关的**事实**照常写（例如 ChamberUp 页上写明站点主人的角色和职责：Project Manager and Product Owner）。但**玩法、版式、视觉和交互都不围绕项目管理的工具或意象**：不做甘特图、路线图、更新日志、看板这类东西。

**P6. 没有地基的笼子。** `[已定]`
不再有"内容最宽 1080px 居中、两侧留空"这种固定框；字体、字号、搭配、布局都可以重新定。

**P7. 内容再少，也要好玩。** `[已定]`
一个页面在没有别人内容的时候（例如留言板长期为空），**也必须已经有趣**；好玩不能依赖访客提供内容。

**P8. 素材。** `[已定]`
图片和视频由站点主人在 ChatGPT 里生成；用什么素材，我们**一起判断**。Claude **不编造、不用自己画的东西冒充**素材。需要素材的地方，由我先写清楚"这里需要一张什么样的图、用来干什么"，再由站点主人生成。

**P9. 诚实。** `[已定]`
不放编造的留言、名字、评价或数据；示例内容必须明确标注是示例；需要的真实内容（状态、收藏等）只放站点主人真有的。

**P10. 固定不变的行为。** `[已定]`
- 留言板：审核机制，访客可以编辑自己待审核的留言、删除自己的留言，这些规则不变。
- 英文为主；中文页保持关闭。

**P11. 已经否掉的方向（不再提）。** `[已定]`
书桌、飞镖房、悉尼线路图、甘特图和项目计划板、"桌面窗口 + 像素风"。弹珠机：不确定。"一个可以走动的场景（小镇）"没有完全否掉，但归入"以后做游戏时再用"，不用在个人站上。

**P12. 手感：鼠标在一块"介质"上拨动，不是触发效果。** `[已定]`（2026-11-14 手感样品测试：站点主人选了 4 点阵、5 雾、8 橡皮筋）
- 喜欢的：鼠标对一块**连续的、有惯性的、抽象的表面**施力——推开一片点、擦开一层雾、拖着一串软球。不需要读字。
- 没选的：对文字做的效果（吸引、解码、速度拉伸）、离散的点击切换、滚动驱动的变化。
- 第二轮（2026-11-14，水、铁屑、布、墨、真毛玻璃、旋涡）：他的反馈是"跟第一轮的 4 5 8 很像，但手感都没有它们好，只有墨（第 4）不错"。结论：水、铁屑、布、真毛玻璃、旋涡都不要；**候选介质收敛为四个：点阵、雾、橡皮筋、墨**。这说明手感的关键不是"介质的种类"，而是第一轮那三个的具体手感参数（点阵弹簧、雾的擦除和回雾、橡皮筋的跟随延迟），实现时要沿用第一轮的参数。
- 点阵的后续（2026-11-14）：放进首页设想后被否，理由是"看着不舒服，可能有人密集恐惧"。**全站避免密集重复的小圆点或小孔洞图案**。候选介质剩：雾、橡皮筋、墨。
- 含义：站点的交互核心是**"一个会回应鼠标的表面"**，内容通过它出现、被它遮住或被它推开。具体用哪一种介质（点阵、雾、软球，或别的），待定。

## 3. World description（草稿，等你逐条改）

> 这是**方向 D** 去掉"故事感"之后剩下的部分，写成文字。每一条都可以被划掉。
> 已删除（2026-11-14，站点主人："太有故事感了"）：小角色、每章不同的鼠标动词、"一句话教会怎么玩"、统一线索。

**3.1 环境（Environment）** `[提议]`
站点有一个**不会重载的环境**：一些常驻的元素一直在，中间的"舞台"在换内容。访客感觉不是"翻页"，而是"在同一个地方里换一样东西看"。进入一个章节是走进舞台，退出（例如按 Esc）是回到环境。
`[待定]`：常驻的元素具体放哪些、放在屏幕的哪些位置、占多大。

**3.2 此刻面板（Presence）** `[提议]`
- 悉尼时间和访客自己的时间并排显示。
- "此刻在做什么 / 在听什么 / 在玩什么"：**只放站点主人真实的内容，不想放就整块不放**。
`[待定]`：放不放、放哪几项、多久更新一次、怎么更新（手动还是自动）。

**3.3 语气和幽默（Voice）** `[提议]`
404、空状态、加载中、"还没写"这些位置，用站点主人自己的口吻。
`[待定]`：具体的话。需要站点主人来写或者口述，我整理。

**3.4 第一屏（Opening）** `[提议，待定具体介质]`
访客进来先看到的是**环境**，而第一屏本身就是一块**会回应鼠标的介质**（P12），鼠标一动就在玩。
`[待定]`：用哪种介质（点阵、雾、软球，或别的）、它的视觉（背景、色彩）、内容怎么通过它出现。**不再有底部教玩法的提示行。**

**3.5 进入和退出（Enter / exit）** `[提议]`
进入一个章节是"走进舞台"，用一个有设计的过渡，不是页面跳转；Esc 或明确的"返回"回到环境。
`[待定]`：过渡长什么样。

**3.6 滚动（Scroll）** `[提议]`
在需要的章节里，滚动被赋予意义（例如推进一个过程、可以倒着滚回去）。不是每个章节都需要。
`[待定]`：哪些章节用，用来做什么。

**3.7 各章的交互（Chapters）** `[待定]`
现有站点的章节：Projects（ChamberUp 项目页，含职责说明）、Stories（目前里面只有 Darts，线上版本 Darts 是 Stories 的子页面）、Guestbook（规则见 P10）、Information（教育、经历、联系方式），**2026-11-14 起 Information 改名为 About Me**。
`[待定]`：每一章里访客能玩什么、怎么玩。**不预设"鼠标动词"这类概念，也不要求每章统一的线索。**

## 5. Constraints

- **只在本地 `v2` 分支**，不提交、不推送；`docs/v2/` 不进 git。线上 `main` 保持 `32ff95c`。`[已定]`
- 沿用 Astro 5 + GitHub Pages，静态站点；部署工作流只在推 `main` 时触发。
- 留言板后端 `guestbook-api/` 不改接口；访客身份靠浏览器令牌哈希，前端必须继续使用同一套。
- 素材（图片、视频）由站点主人在 ChatGPT 生成，我不编造、不用自己画的东西冒充。`[已定]`
- 不放编造的留言、名字、数据；示例必须标注为示例。`[已定]`
- 英文为主。`[已定]`
- 性能：点阵、雾、橡皮筋、墨都是 canvas 动画，必须只在可见时运行，同屏最多一个重介质；手机上降低点数。
- 可访问性：键盘可以操作所有章节和留言板；`prefers-reduced-motion` 下介质降级为静态；内容不能只靠擦雾才能读到（要有可读的退路）。
- 已知限制：雾遮住内容时，搜索引擎和读屏软件仍要读到真实文字，所以雾只能是视觉层。
