## 施工中磨坊：参考与要点（2026-11-14）
- 用 Chrome 看了 Bing 图片搜索共五组（像素建筑施工脚手架、星露谷 Robin 建筑施工与社区中心破旧状态、像素自上而下房屋施工、施工场地瓦片集）。
- 观察：好的"施工中"不是把成品房子加几件工具，而是**房子本身是半成品**：砖/墙只砌了一半（下半实上半空）、**外面一圈金属或木杆脚手架，层层有横板**、一侧**斜梯**、顶部露出骨架、地上散落材料（砖堆、木料、桶）。星露谷的 Robin 施工是**一圈木桩围住的空地，中间一座小棚子的框架**，而不是完整的房子。
- 之前 ChatGPT 生成的那张施工版，问题是房子主体仍是完整的，只是叠了脚手架和工具，所以施工感弱。
- 新做法：**房子只建到一半**：石头底座完成，一层木墙只做了一半，二层只有木框架（梁和柱，没有墙板），屋顶只铺了一半、另一半是裸露椽子，脚手架从底到顶，一侧斜梯，砖堆、木料堆、水泥桶、手推车，帆布盖着一部分。
- 2026-11-14 磨坊确定为"施工中"状态（未解锁、不可进入，以后建好可变成第五个入口）：`raw/buildings/像素风水车木屋施工现场.png`，抠图 `processed/buildings/mill_construction_cut.png`。水车是只剩骨架的静态木框，站在左墙外，不转。碰撞范围：房子底座加水车区域（用自动算法）。
