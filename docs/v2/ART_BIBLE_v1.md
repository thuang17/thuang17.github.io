# 美术标准（Art Bible）v1

状态：草稿，2026-11-15。位置：`docs/v2/`，不提交。
用途：所有像素素材（建筑、角色、地面、自然物、小物件、动物、界面）都必须符合本标准。不符合的，先过统一处理程序；处理后仍不搭的，重新生成。
本文件取代 `ASSET_BRIEF_v1.md` 里与它冲突的规格（例如旧的"一格 32 像素、角色 1.5 格高"）。

---

## 1. 基本单位

| 项目 | 规定 |
|---|---|
| 一格（tile） | **32 × 32 美术像素** |
| 屏幕显示 | 美术像素按**整数倍**放大显示，默认 2 倍（一格 = 64 屏幕像素），只用最近邻缩放，不做平滑 |
| 角色 | **1.5 格高**（48 美术像素），约 1 格宽（2026-11-15 站点主人决定：2 格太大，改回 1.5 格） |
| 像素粗细 | 全镇只有一种像素粗细：任何素材都先缩回 32 像素一格的网格，再整数放大 |

依据：星露谷的地砖是 16×16 像素，NPC 和玩家是 16×32 像素（玩家 2 格高）。我们沿用这个比例，分辨率翻一倍（32 像素一格），因为我们的素材细节更多。来源见第 9 节。

## 2. 尺寸表（以角色身高为尺子）

角色 = 1.5 格高（记作 1P）。2026-11-15 站点主人明确：**素材本来就偏小，不能再缩小，只能放大**；不再按现实比例推算，以他看着合适为准。以下是屏幕上的大小，单位是格；每个文件的具体数值以 `tools/sizes.json` 为准，改尺寸只改那里。

| 类别 | 规定 |
|---|---|
| 入口建筑（Projects、Stories、Guestbook、About Me） | 宽 5～8 格 |
| 施工中磨坊 | 宽约 7 格 |
| 大树（阔叶、柳、棕榈、云杉） | 高约 5～5.8 格 |
| 中树（开花树、白桦、杨树、扭曲树、双生树） | 高约 4.2～5.4 格 |
| 小树（树苗、小树、园艺树） | 高约 1.5～3.4 格 |
| 灌木、蕨、尖叶草 | 宽约 1.5～2.3 格 |
| 大石头 | 宽约 2.6 格；小石头约 1 格 |
| 井 | 宽约 2.6 格 |
| 长椅 | 宽约 2.5 格 |
| 路灯 | 高约 3.8 格 |
| 告示板、花槽、木箱、木桶 | 宽约 1.9～2.1 格 |
| 信箱 | 高约 1.9 格；路牌高约 2.3 格 |
| 小船 | 宽约 2.8 格 |
| 水边植物 | 芦苇约 2 格高，睡莲约 2.2 格宽 |

注意：尺寸调整顺序是"先看效果再改数字"，不要凭公式推。

## 3. 颜色

- **主色板**：48 色，存在 `tools/palette.json`，预览图在 `assets/processed/previews/master_palette.png`。
- 主色板从站点主人认可的素材里提取（玻璃花房、观星小屋、魔法村舍、集市厅、地面、几棵春夏的树、井、路灯），并**保留**地面的原色（草、沙、水不会变色），以及几组小面积的点缀色（淡紫花、窗户暖光、青色）。
- 所有素材的每一个像素都必须是主色板里的颜色。统一处理程序会自动把颜色吸到最近的主色。
- 禁止：粉红、玫红、洋红（洋红是抠图背景色）、纯黑。

## 4. 描边、光照、明暗

| 项目 | 规定 |
|---|---|
| 描边 | 物体最外一圈，**一个美术像素宽**，颜色固定为暖深棕 `#4B3025`。程序会统一重画最外圈 |
| 地面 | 地面格不描边 |
| 光源 | 统一从左上方来 |
| 阴影 | 物体脚下的投影由代码统一生成（淡紫色、压扁、方向一致），素材本身不画地面阴影 |
| 明暗 | 每种材质 2～3 层色阶，不用渐变、不用喷枪式的光滑过渡、不用高光反射 |

## 5. 视角

- 全部是俯视略带斜角（看得到建筑正面和屋顶）。
- 建筑的门一律朝画面下方。
- 侧面的东西（例如侧面看的水车）只能出现在建筑轮廓之外，不能压在建筑上。

## 6. 季节

- **第一版只有春天。** 只用春夏的绿树、白花和淡紫花树、春天的地面。
- 秋天的橙树、金黄树、冬天的光秃树**保留文件，但第一版不用**。季节变化留到以后的版本。
- 新生成的自然物素材，一律按春天来画。

## 7. 统一处理程序（`tools/normalize.py`）

每张 ChatGPT 生成的图，抠图后都要过这一步才能进镇子：

1. 按 `sizes.json` 的尺寸，把图缩到"32 像素一格"的真实网格（面积平均，不是丢像素）。
2. 透明度变成只有"全透明 / 全不透明"两种，去掉半透明毛边。
3. 每个像素吸到主色板里最近的颜色，不做抖动。
4. 最外一圈重画为统一的描边色。

用法：

```
cd docs/v2/tools
python3 normalize.py palette   # 重新提取主色板（只在锚点素材变化时做）
python3 normalize.py run       # 处理 sizes.json 里列出的所有素材
```

结果放在 `assets/normalized/`，目录结构和 `processed/` 一样。游戏只读 `normalized/`。

## 8. 生成新素材的流程

1. **新开一个 ChatGPT 对话**，先附上两张"标准样图"（目前是玻璃花房和观星小屋），再贴风格前缀。
2. 一次只画一类东西，每格一件，留足间距，洋红背景。
3. 生成后先抠图，再过统一处理程序，再拼进镇子里看。
4. 按第 10 节的检查表验收，任何一项不过就重做或调整。

## 9. 参考来源（2026-11-15 查证）

- 星露谷地砖 16×16 像素、NPC 16×32 像素：[官方论坛的 modding 讨论](https://forums.stardewvalley.net/goto/post?id=41876)，[地图教程](https://stardewvalleywiki.com/Modding:Maps)。
- 星露谷建筑和树的格数：从星露谷 wiki 文件的图片尺寸推算（wiki 图片是原图放大 3～4 倍）：谷仓约 7×7 格，井约 3 格宽、约 4.7 格高，磨坊约 4 格宽、8 格高，橡树约 3 格宽、6 格高。树的数据是近似值，未用游戏原文件核对。
- Core Keeper 和泰拉瑞亚：泰拉瑞亚的地砖是 16×16 像素有多个来源可证；Core Keeper 的官方像素规格没查到，所以本标准不引用它。

## 10. 验收检查表（每张新素材都过一遍）

- [ ] 像素粗细和镇子里其他东西一样（放进镇子看，不只是单独看）
- [ ] 所有颜色都在主色板里
- [ ] 描边是一个像素宽的暖深棕
- [ ] 光从左上来，明暗不超过 3 层，没有渐变和高光
- [ ] 尺寸符合第 2 节，放在角色旁边比例对
- [ ] 视角一致，门朝下
- [ ] 春天
- [ ] 没有粉红、洋红、纯黑，没有文字

## 11. 字体（2026-11-15）

- 全站唯一字体：**Jersey 15**（Google Fonts，SIL Open Font License，可用于公开网站）。站点主人选它因为"最好读"。
- 对比过的候选：Pixelify Sans、Jersey 10、Silkscreen、VT323、Tiny5、Micro 5、Handjet、Press Start 2P；对比页在 `town/fonts.html`。
- 只有一个字重。**不用浏览器的假粗体**（会让像素变形），强调靠字号和颜色。
- 字号尽量用整数倍的"像素格"：先选一个基准字号，再用它的整数倍，让文字像素和小镇的像素粗细保持一致。具体数值在做木板组件时定。
- 不支持中文。中文页保持关闭；将来要开，另选字体。
- 字体文件最好**自己托管**（下载到网站里，随页面发布），不依赖谷歌的服务器，也不向谷歌泄露访客的访问。下载前再次确认许可文件。
- 不用任何商业游戏的字体（星露谷、泰拉瑞亚等）。
