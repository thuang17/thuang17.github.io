# Personal Website V2 — 开发计划（一页，v1 草稿）

位置：本地 `v2` 分支，`docs/v2/`，不提交、不推送。对应 `PRD_v1.md`。
原则：每个阶段结束都有一个**你能在本地亲手玩的东西**，你说"可以"才进下一阶段；任何阶段都可以停，停了就删分支，线上不受影响。

| 阶段 | 做什么 | 你能玩到什么 | 阶段里要你定的（对应 PRD 第 6 节） |
|---|---|---|---|
| 0 地基 | 清空旧样式；定字体、字号、色彩、间距；做一个共用的介质模块（canvas，只在可见时运行，支持降级），沿用第一轮样品的手感参数 | 一个空页面，上面只有第一屏的介质（点阵已否，待重选） | 第一屏用哪种介质、色彩和背景（Q3） |
| 1 第一屏 + 一个章节 | 点阵第一屏，名字和一句话通过点阵出现；橡皮筋光标；做进出舞台的雾，用 Projects（ChamberUp）验证 | 进站 → 拨点阵 → 进 ChamberUp（雾擦开）→ Esc 退出（雾重新盖上） | 雾盖整屏还是只盖入口（Q4）；光标是否取代旧圆点、触屏替代（Q6）；环境常驻元素（Q1） |
| 2 其他章节 | Stories、Darts、Information 搬进新舞台；404 和空状态 | 五个章节里只剩留言板没换 | 每章除了介质外还玩什么（Q5）；语气文案（Q9）；此刻面板放不放（Q2） |
| 3 留言板 | 前端移植，墨迹层；后端接口、令牌、审核、编辑和删除规则全部不变 | 能留言、改、删，和线上行为一致，页面上能划墨 | 无 |
| 4 打磨 | 手机端、性能（低端机降点数）、键盘操作、减少动效降级、读屏和 SEO 文字 | 手机和键盘都能完整走一遍 | 素材清单（Q8）、静音开关取舍（Q7） |
| 5 决定 | 你整站走一遍，对比线上版 | 你决定：合并上线，或删分支 | 合并标准（Q10） |

## 每阶段的检查（我做完才交给你）
- 浏览器控制台无报错；`npm run build` 通过。
- 留言板相关（阶段 3、5）：用本地后端或测试数据验证，不写入线上数据库。
- 只在 `v2` 分支提交，不推送；`git status` 里 `docs/v2/` 保持未跟踪。

## 风险
- **手感退化**：把样品搬进正式页面后，手感可能变。对策：阶段 0 就把参数固定在共用模块，后面各处只调用，不重调。
- **雾遮内容**：雾必须是视觉层，文字真实存在于页面里。阶段 1 就验证读屏和 SEO，不拖到最后。
- **移动端性能**：四种介质都是 canvas。对策：只在可见时运行，同屏一个重介质，阶段 4 实测。
- **范围蔓延**：新增玩法一律先记入 PRD 第 6 节，再决定，不在阶段中途加。
