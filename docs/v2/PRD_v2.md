## 1. 这是什么

**1.1 一句话。** V2 是个人网站的完整重做：**首页就是一个像素风的小镇，访客可以走动、走到建筑门口互动，感觉像是在玩一个沙盒游戏。** 内容、留言板后端、域名、部署方式沿用。`[已定]`

**1.2 它不是什么。**
- 不是求职站，访客是任何人。`[已定]`
- 不是现有网站的小修小补。`[已定]`
- 不追求极简。`[已定]`
- 不是真的游戏产品，不做战斗、背包、任务系统。（访客不能砍树、挖矿。站点主人自己有建造模式，见 3.6。）`[提议]`

**1.3 谁拥有它。** 站点主人有绝对的掌控权和自由。`[已定]`

**1.4 它怎么存在。** 只存在于本地 `v2` 分支，线上网站保持原样。站点主人明确接受之后才合并上线；不接受就整个分支删除。`[已定]`

**1.5 访客的体验目标。** 打开页面，第一眼看到一个暖色的小镇，角色站在广场上；走几步就明白"这是个可以玩的地方"；走到某栋房子旁边出现提示，按键进入对应的内容。想直接看内容、不想走路的人，有一个菜单可以直达（3.5）。`[已定]`

## 2. 原则

**P1. 大胆，且别处没有。** `[已定]`

**P2. 交互是主角。** 页面本身就是一个可以玩的场景。`[已定]`

**P3. 事实，不是题材。** 项目管理相关的事实照常写（ChamberUp 页上写明站点主人的角色：Project Manager and Product Owner）。但**视觉和玩法不围绕项目管理的工具或意象**：不做甘特图、路线图、更新日志、看板。`[已定]`

**P4. 内容再少也要好玩。** 留言板长期为空时页面也已经有趣，好玩不能依赖访客提供内容。`[已定]`

**P5. 素材来源和分工。** 图片由站点主人在 ChatGPT 生成。**Claude 不画素材，也不替站点主人判断他做得到做不到**：规模由他定，我只说技术上的真实限制。Claude 负责抠图、统一处理、写代码。`[已定]`

**P6. 诚实。** 不放编造的留言、名字、评价或数据；示例必须标注；只放站点主人真有的内容。`[已定]`

**P7. 固定不变的行为。** 留言板的审核机制、访客可编辑自己待审核的留言和删除自己的留言，这些规则不变。英文为主，中文页保持关闭。`[已定]`

**P8. 像做真游戏一样做。** 用正规的方法：先定美术标准，再做素材，再做处理程序，再拼场景，再在编辑器里摆。每一步查真实游戏怎么做（星露谷、Core Keeper 等），而不是凭感觉。`[已定]`（站点主人 2026-11-15："把它当成一个游戏来做，用一个非常正规的方法"）

**P9. 美术标准是硬规则。** 全站所有素材必须符合 `ART_BIBLE_v1.md`（一格 32 美术像素、整数倍放大、48 色主色板、一像素暖深棕描边、左上光源、春天一套）。不符合的素材先过统一处理程序，处理后仍不搭的重新生成。`[已定]`

**P10. 素材只放大，不缩小。** 素材本来就偏小；尺寸以站点主人看着合适为准，数字集中在 `tools/sizes.json`，不凭公式推算。`[已定]`

**P11. 第一版只有春天。** 季节变化留到以后的版本。秋天、冬天的素材文件保留但不使用。`[已定]`

**P12. 已经否掉的方向（不再提）。**
- 鼠标拨动一块"介质"那一整套：点阵（引发密集恐惧）、雾盖住首页、墨、橡皮筋光标、水、铁屑、布、毛玻璃、旋涡。
- 首页放一个很大的名字、渐变加大名字、圆角彩色方块拼贴（"AI 味太浓"）、太空的纯色块。
- 暗冷的魔法色板（深青、梅紫、玫红加黑描边，"太诡异"）。
- 圆桶形的建筑、石头堆叠的石墩、圆形水车压在房子上。
- 点击后自动绕路寻路（直走，被挡住就停下）。
- 甘特图和项目计划板、书桌、飞镖房、悉尼线路图。
- Bruno Simon 那种 3D 场景（留给以后的游戏项目）。
- 用站点主人的卡通头像做主角（他不喜欢）。
`[已定]`

## 3. 世界和玩法

**3.1 小镇布局。** `[已定]`（2026-11-14 选定"广场加水岸"混合版面；细节会在建造模式里由站点主人自己调）
- 中央一块沙色广场，正中一口井，周围长椅和路灯。
- 一条主轴从广场向北，直达最高的 **Projects**（魔法村舍），它是视觉焦点。
- **Stories**（玻璃花房）在西，**Guestbook**（集市厅）在东，前后错开，不排成一条直线。
- **About Me**（观星小屋）在西南靠水。
- **磨坊**在东南岸边，**目前是施工中、不可进入**，以后建好可以变成第五个入口。
- 南边是弯曲的海湾，沙岸，栈桥、小船、钓鱼架；树围出镇子的边。
- 路有主次：宽的主路，一格宽的小径通向每个门。
- 门一律朝画面下方。
- 参照真实星露谷鹈鹕镇的设计：路网分层、水岸蜿蜒、沙岸、树当边界。
- 广场先保持沙色，以后迭代再换石板；悬崖、桥以后再加。

**3.2 角色。** `[已定]`
- **披青色斗篷的旅人**，代表访客，不是站点主人本人。
- 1.5 格高，四个方向的走路动画（每个方向 6 帧）和站立（2 帧，会轻微呼吸）。斜向走时显示左右朝向。
- 键盘 WASD 或方向键走路；**点击地面朝点击处直走，被挡住超过 0.25 秒就停下**，走路动画同时变成站立。
- 速度约每秒 5.4 格，镜头平滑跟随，只能按 0.5 一档整数缩放。

**3.3 入口和互动。** `[已定]`
- 四个入口：**Projects**（ChamberUp 项目页，含职责说明）、**Stories**（里面包含 Darts，按线上版本的包含关系）、**Guestbook**、**About Me**（原 Information）。
- 角色**贴着建筑边缘**时（正面、左右、被建筑遮住的背面），屏幕下方出现提示，按 E 或回车互动；离开约 0.3 格提示消失。
- 磨坊四面都提示"施工中，还不能进"。
- **互动之后，从屏幕正中间打开一块木头告示板**（站点主人 2026-11-15 定的）：
  - 是木板材质，带木纹，画风和小镇统一（同一个像素粗细、色板、一像素暖深棕描边）。
  - 这个入口的**全部内容**都在板上。
  - **不铺满屏幕**，但占大部分；四周还能看到后面的小镇。
  - **右边有一根可以拖动的滚动条**，样式也是像素风，功能和网页的滚动条一样；内容比板子长时用它往下滑。
  - **右上角有一个叉**，点它或按 Esc 关闭，回到小镇。
  - **板上所有文字用同一套像素风字体**：**Jersey 15**（2026-11-15 站点主人选定，因为最好读；Google Fonts，SIL Open Font License，可以用在公开网站上）。全站所有地方都用它。
- 这块板是网页里的真实文字（DOM），不是画在画布上的图，所以可以选中、搜索、被读屏软件读到。`[提议]`

**3.4 碰撞和遮挡。** `[已定]`
- 所有物体的碰撞范围从图片底部像素自动算出，树只取树干中段；水格整格不可走，角色离水保持约 0.3 格。
- 物体按脚底位置前后遮挡。物体阴影由代码统一生成（淡紫色、向后偏）。

**3.5 菜单（直达）。** `[提议]` `[待定]`
不想走路的访客用一个常驻的菜单（左、右、上或下，位置待定）直接选 Projects、Stories 等，看内容。也是读屏和键盘用户的退路。位置、样式待定。

**3.6 建造模式（只给站点主人）。** `[已定]`（2026-11-15）
- 只在本机（localhost）打开，上线后访客那边没有这个功能。
- 热键栏（一行 10 格加一只"手"）加背包（五个分类），点地面摆放物体；手工具拖动，右键或 Delete 删除；G 对齐网格，C 显示碰撞，Ctrl+Z 撤销；Shift+点击传送角色。
- 布局自动保存到 `docs/v2/town/layout.json`；"恢复默认布局"可撤销。
- 目前只能编辑物体，**不能编辑地形**（站点主人 2026-11-15："编辑地形先不管"）。

**3.7 此刻面板、语气。** `[提议]` `[待定]`
悉尼时间和访客自己的时间并排显示；404、空状态用站点主人自己的口吻。放不放、放哪、具体的话都待定。

**3.8 以后的版本。** `[提议]`
钓鱼等小游戏；水面和水车的逐帧动画；动物（蝴蝶、鸟、鸭子）；季节变化；站点主人自己编辑地形；菜单直达；背景音乐和音效（带静音开关）。都不在第一版。

4. 留言板前端移植到新设计，后端和规则不变（Cloudflare Worker 加 D1）。**接真后端放到 V2 真正要上线、要替换线上版本的时候再做**（站点主人 2026-11-15）。在那之前留言板用示例数据，发送是模拟的。`[已定]`
5. 美术标准、统一处理程序、`sizes.json` 作为素材流水线保留。`[已定]`

8. 有真实文字的备用导航（语义化 HTML 链接列表），保证搜索引擎和读屏软件读得到。`[提议]`

- 季节变化、水面和水车动画、动物、钓鱼。

- 访客能砍树、挖矿、摆放物品。

## 5. 约束

- 只在本地 `v2` 分支，不提交、不推送；`docs/v2/` 不进 git（已加入 `.git/info/exclude`）。线上 `main` 保持 `32ff95c`。`[已定]`
- 沿用 Astro 5 加 GitHub Pages，静态站点；留言板后端接口不改，访客身份仍靠浏览器令牌哈希。
- 所有素材符合 `ART_BIBLE_v1.md`；尺寸改 `tools/sizes.json`；改完用 `tools/normalize.py run` 重新处理，再 `tools/sync_town_assets.py` 同步到页面。
- 素材由 ChatGPT 生成。我不是律师：纯 AI 生成的图片在澳大利亚、美国可能得不到版权保护，上线前再看一次 OpenAI 当时的使用条款。已经决定以后这些素材也可能用于站点主人的另一个像素游戏。
- 性能：只画镜头里看得到的地面；地面预渲染成一张图；物体每帧排序，数量约 150（只测桌面）。
- 可访问性：键盘能操作；`prefers-reduced-motion` 下角色移动动画和呼吸减弱；画布上的内容必须有 HTML 备用版。
- 角色、建筑、树等所有图片是像素图，不用平滑缩放（最近邻）。
